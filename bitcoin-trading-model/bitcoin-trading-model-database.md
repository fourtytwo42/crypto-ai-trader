## Schema Overview

The database stores:
- **Raw candle data** from Kraken CSV files
- **Engineered features** (log returns, range, volume, etc.)
- **Model metadata** (configurations, training parameters)
- **Predictions** generated by models
- **Backtest results** (metrics, trades, P&L)

## Tables

### 1. candles

Stores raw OHLCV candle data from Kraken.

```sql
CREATE TABLE candles (
    id SERIAL PRIMARY KEY,
    timestamp TIMESTAMP WITH TIME ZONE NOT NULL,
    open NUMERIC(20, 8) NOT NULL,
    high NUMERIC(20, 8) NOT NULL,
    low NUMERIC(20, 8) NOT NULL,
    close NUMERIC(20, 8) NOT NULL,
    volume NUMERIC(20, 8) NOT NULL,
    trades INTEGER,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    UNIQUE(timestamp)
);

CREATE INDEX idx_candles_timestamp ON candles(timestamp);
CREATE INDEX idx_candles_created_at ON candles(created_at);
```

**Columns:**
- `id`: Primary key
- `timestamp`: Candle timestamp (UTC)
- `open`, `high`, `low`, `close`: Price in USD
- `volume`: Trading volume
- `trades`: Number of trades (optional)
- `created_at`: Record creation time

**Constraints:**
- `timestamp` must be unique (prevent duplicates)
- All price fields must be positive
- `high >= low`, `close` in `[low, high]`

### 2. features

Stores engineered features computed from candles.

```sql
CREATE TABLE features (
    id SERIAL PRIMARY KEY,
    candle_id INTEGER NOT NULL REFERENCES candles(id) ON DELETE CASCADE,
    timestamp TIMESTAMP WITH TIME ZONE NOT NULL,
    return NUMERIC(20, 8),
    range NUMERIC(20, 8),
    body NUMERIC(20, 8),
    dlog_volume NUMERIC(20, 8),
    ret_mean_7 NUMERIC(20, 8),
    ret_std_7 NUMERIC(20, 8),
    ret_mean_30 NUMERIC(20, 8),
    ret_std_30 NUMERIC(20, 8),
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    UNIQUE(timestamp)
);

CREATE INDEX idx_features_timestamp ON features(timestamp);
CREATE INDEX idx_features_candle_id ON features(candle_id);
```

**Columns:**
- `id`: Primary key
- `candle_id`: Foreign key to candles table
- `timestamp`: Feature timestamp (matches candle timestamp)
- `return`: Log return `log(C_t / C_{t-1})`
- `range`: Log range `log(H_t / L_t)`
- `body`: Log body `log(C_t / O_t)`
- `dlog_volume`: Change in log volume
- `ret_mean_7`, `ret_std_7`: 7-day rolling stats
- `ret_mean_30`, `ret_std_30`: 30-day rolling stats

### 3. models

Stores model metadata and configurations.

```sql
CREATE TABLE models (
    id SERIAL PRIMARY KEY,
    name VARCHAR(255) NOT NULL UNIQUE,
    model_type VARCHAR(50) NOT NULL,  -- 'patchtst', 'nhits', 'tsmixer'
    version VARCHAR(50) NOT NULL,
    file_path VARCHAR(500) NOT NULL,  -- Path to .pt file
    scaler_path VARCHAR(500),  -- Path to scaler .pkl file
    config JSONB NOT NULL,  -- Training configuration
    train_start TIMESTAMP WITH TIME ZONE,
    train_end TIMESTAMP WITH TIME ZONE,
    val_start TIMESTAMP WITH TIME ZONE,
    val_end TIMESTAMP WITH TIME ZONE,
    test_start TIMESTAMP WITH TIME ZONE,
    test_end TIMESTAMP WITH TIME ZONE,
    metrics JSONB,  -- Validation/test metrics
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

CREATE INDEX idx_models_name ON models(name);
CREATE INDEX idx_models_type ON models(model_type);
CREATE INDEX idx_models_created_at ON models(created_at);
```

**Columns:**
- `id`: Primary key
- `name`: Model name (e.g., "model_v1", "patchtst_daily_v1")
- `model_type`: Type of model
- `version`: Model version
- `file_path`: Path to saved model weights
- `scaler_path`: Path to saved scaler
- `config`: Training configuration (JSON)
- `train_start`, `train_end`: Training period
- `val_start`, `val_end`: Validation period
- `test_start`, `test_end`: Test period
- `metrics`: Performance metrics (JSON)

**Config JSON Structure:**
```json
{
  "context_length": 128,
  "horizon": 1,
  "hidden_size": 512,
  "num_layers": 6,
  "learning_rate": 0.0001,
  "batch_size": 32,
  "epochs": 100,
  "quantiles": [0.1, 0.5, 0.9]
}
```

### 4. predictions

Stores predictions generated by models.

```sql
CREATE TABLE predictions (
    id SERIAL PRIMARY KEY,
    model_id INTEGER NOT NULL REFERENCES models(id) ON DELETE CASCADE,
    timestamp TIMESTAMP WITH TIME ZONE NOT NULL,  -- Prediction time
    prediction_timestamp TIMESTAMP WITH TIME ZONE NOT NULL,  -- What we're predicting
    q10 NUMERIC(20, 8),  -- 10th percentile
    q50 NUMERIC(20, 8),  -- Median (50th percentile)
    q90 NUMERIC(20, 8),  -- 90th percentile
    signal VARCHAR(10),  -- 'long', 'short', 'flat'
    threshold NUMERIC(10, 6),  -- Threshold used for signal
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    UNIQUE(model_id, prediction_timestamp)
);

CREATE INDEX idx_predictions_model_id ON predictions(model_id);
CREATE INDEX idx_predictions_timestamp ON predictions(timestamp);
CREATE INDEX idx_predictions_prediction_timestamp ON predictions(prediction_timestamp);
CREATE INDEX idx_predictions_signal ON predictions(signal);
```

**Columns:**
- `id`: Primary key
- `model_id`: Foreign key to models table
- `timestamp`: When prediction was made
- `prediction_timestamp`: What timestamp we're predicting (next day)
- `q10`, `q50`, `q90`: Quantile predictions
- `signal`: Generated signal
- `threshold`: Threshold used for signal generation

### 5. backtests

Stores backtest run metadata.

```sql
CREATE TABLE backtests (
    id SERIAL PRIMARY KEY,
    model_id INTEGER NOT NULL REFERENCES models(id) ON DELETE CASCADE,
    name VARCHAR(255) NOT NULL,
    start_date TIMESTAMP WITH TIME ZONE NOT NULL,
    end_date TIMESTAMP WITH TIME ZONE NOT NULL,
    train_window INTEGER,  -- Days in training window
    test_window INTEGER,  -- Days in test window
    fees NUMERIC(10, 6),  -- Fee rate (e.g., 0.001 for 0.1%)
    slippage NUMERIC(10, 6),  -- Slippage rate
    metrics JSONB NOT NULL,  -- Overall metrics
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

CREATE INDEX idx_backtests_model_id ON backtests(model_id);
CREATE INDEX idx_backtests_start_date ON backtests(start_date);
CREATE INDEX idx_backtests_end_date ON backtests(end_date);
```

**Columns:**
- `id`: Primary key
- `model_id`: Foreign key to models table
- `name`: Backtest name
- `start_date`, `end_date`: Backtest period
- `train_window`, `test_window`: Window sizes for walk-forward
- `fees`, `slippage`: Cost assumptions
- `metrics`: Overall backtest metrics (JSON)

**Metrics JSON Structure:**
```json
{
  "total_return": 0.15,
  "sharpe_ratio": 1.2,
  "win_rate": 0.58,
  "avg_win": 0.02,
  "avg_loss": -0.015,
  "max_drawdown": -0.08,
  "num_trades": 150,
  "turnover": 0.5
}
```

### 6. backtest_trades

Stores individual trades from backtests.

```sql
CREATE TABLE backtest_trades (
    id SERIAL PRIMARY KEY,
    backtest_id INTEGER NOT NULL REFERENCES backtests(id) ON DELETE CASCADE,
    entry_timestamp TIMESTAMP WITH TIME ZONE NOT NULL,
    exit_timestamp TIMESTAMP WITH TIME ZONE NOT NULL,
    signal VARCHAR(10) NOT NULL,  -- 'long' or 'short'
    entry_price NUMERIC(20, 8) NOT NULL,
    exit_price NUMERIC(20, 8) NOT NULL,
    pnl NUMERIC(20, 8) NOT NULL,
    fees NUMERIC(20, 8) NOT NULL,
    slippage NUMERIC(20, 8) NOT NULL,
    net_pnl NUMERIC(20, 8) NOT NULL,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

CREATE INDEX idx_backtest_trades_backtest_id ON backtest_trades(backtest_id);
CREATE INDEX idx_backtest_trades_entry_timestamp ON backtest_trades(entry_timestamp);
CREATE INDEX idx_backtest_trades_exit_timestamp ON backtest_trades(exit_timestamp);
```

**Columns:**
- `id`: Primary key
- `backtest_id`: Foreign key to backtests table
- `entry_timestamp`, `exit_timestamp`: Trade timestamps
- `signal`: Trade direction
- `entry_price`, `exit_price`: Trade prices
- `pnl`: Gross profit/loss
- `fees`, `slippage`: Costs
- `net_pnl`: Net profit/loss after costs

## Relationships

```
candles (1) ──< (1) features
models (1) ──< (*) predictions
models (1) ──< (*) backtests
backtests (1) ──< (*) backtest_trades
```

**Foreign Keys:**
- `features.candle_id` → `candles.id` (CASCADE delete)
- `predictions.model_id` → `models.id` (CASCADE delete)
- `backtests.model_id` → `models.id` (CASCADE delete)
- `backtest_trades.backtest_id` → `backtests.id` (CASCADE delete)

## Indexes

### Performance Indexes

- `idx_candles_timestamp`: Fast time-range queries
- `idx_features_timestamp`: Fast feature lookups by time
- `idx_predictions_model_id`: Fast prediction queries by model
- `idx_predictions_prediction_timestamp`: Fast prediction lookups
- `idx_backtest_trades_backtest_id`: Fast trade queries by backtest

### Unique Constraints

- `candles.timestamp`: Prevent duplicate candles
- `features.timestamp`: Prevent duplicate features
- `models.name`: Prevent duplicate model names
- `predictions(model_id, prediction_timestamp)`: Prevent duplicate predictions

## Sample Queries

### Get Latest Candles

```sql
SELECT * FROM candles
ORDER BY timestamp DESC
LIMIT 100;
```

### Get Features for Training

```sql
SELECT f.*, c.close
FROM features f
JOIN candles c ON f.candle_id = c.id
WHERE f.timestamp >= '2013-10-06'
  AND f.timestamp <= '2019-12-31'
ORDER BY f.timestamp;
```

### Get Model Predictions

```sql
SELECT p.*, m.name as model_name
FROM predictions p
JOIN models m ON p.model_id = m.id
WHERE m.name = 'model_v1'
ORDER BY p.prediction_timestamp DESC
LIMIT 10;
```

### Get Backtest Results

```sql
SELECT 
    b.name,
    b.metrics->>'total_return' as total_return,
    b.metrics->>'sharpe_ratio' as sharpe_ratio,
    b.metrics->>'win_rate' as win_rate,
    COUNT(bt.id) as num_trades
FROM backtests b
LEFT JOIN backtest_trades bt ON b.id = bt.backtest_id
WHERE b.model_id = 1
GROUP BY b.id, b.name, b.metrics
ORDER BY b.created_at DESC;
```

### Get Trade History

```sql
SELECT 
    bt.entry_timestamp,
    bt.exit_timestamp,
    bt.signal,
    bt.entry_price,
    bt.exit_price,
    bt.net_pnl
FROM backtest_trades bt
WHERE bt.backtest_id = 1
ORDER BY bt.entry_timestamp;
```
